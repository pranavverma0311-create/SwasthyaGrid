# SwasthyaGrid - Database Schema (Planned)

Database Engine: **MongoDB** with **Mongoose ODM**  
Geospatial Indexing: **2dsphere** on GeoJSON coordinates `[longitude, latitude]`

---

## 1. `users` Collection
Stores authentication, profile, and role-based permissions.

```javascript
{
  _id: ObjectId,
  name: String,               // e.g. "Dr. Anita Sharma"
  email: { type: String, unique: true, index: true },
  passwordHash: String,       // bcrypt hashed
  role: { 
    type: String, 
    enum: ["CITIZEN", "HEALTH_WORKER", "HEALTH_OFFICER", "ADMIN"],
    default: "CITIZEN" 
  },
  phone: String,
  assignedWard: String,       // For health workers/officers (e.g., "Ward 14")
  facilityId: ObjectId,       // Ref to facilities
  isActive: { type: Boolean, default: true },
  createdAt: ISODate,
  updatedAt: ISODate
}
```

---

## 2. `reports` Collection
Stores incoming citizen and frontline health worker symptom signals.

```javascript
{
  _id: ObjectId,
  submittedBy: { type: ObjectId, ref: 'users', required: false }, // Optional for anonymous citizen reporting
  reporterType: { type: String, enum: ["CITIZEN", "HEALTH_WORKER"] },
  symptoms: [String],         // e.g. ["fever", "vomiting", "acute diarrhea"]
  symptomNotes: String,       // Free-text description
  onsetDate: ISODate,
  affectedPeopleCount: { type: Number, default: 1 },
  location: {
    type: { type: String, enum: ['Point'], default: 'Point' },
    coordinates: [Number],    // [longitude, latitude] - indexed with 2dsphere
    address: String,
    ward: String,
    pincode: String
  },
  environmentalFactors: {
    waterSource: String,      // e.g. "Municipal Tap", "Borewell", "Storage Tank"
    drainageIssues: Boolean,
    recentFlooding: Boolean
  },
  clusterId: { type: ObjectId, ref: 'clusters', default: null },
  isVerified: { type: Boolean, default: false },
  createdAt: ISODate,
  updatedAt: ISODate
}
```

---

## 3. `clusters` Collection
Represents identified spatial-temporal clusters generated by the Risk Engine.

```javascript
{
  _id: ObjectId,
  title: String,              // e.g., "Acute Gastrointestinal Cluster - Ward 7"
  centerLocation: {
    type: { type: String, enum: ['Point'], default: 'Point' },
    coordinates: [Number]     // [longitude, latitude]
  },
  radiusMeters: Number,       // e.g. 500
  ward: String,
  reportCount: Number,        // Count of member reports
  reportIds: [{ type: ObjectId, ref: 'reports' }],
  primarySymptoms: [String],  // Ranked predominant symptoms
  priorityScore: {            // Computed 0 - 100 explainable score
    type: Number,
    min: 0,
    max: 100,
    index: true
  },
  severityTier: { 
    type: String, 
    enum: ["LOW", "ELEVATED", "HIGH", "CRITICAL"] 
  },
  explainability: {
    summary: String,          // Natural language rationale
    contributingFactors: [
      { factor: String, weight: Number, description: String }
    ]
  },
  status: {
    type: String,
    enum: ["DETECTED", "TASK_DISPATCHED", "FIELD_VERIFIED", "RESOLVED", "FALSE_ALARM"],
    default: "DETECTED"
  },
  detectedAt: ISODate,
  resolvedAt: ISODate,
  createdAt: ISODate,
  updatedAt: ISODate
}
```

---

## 4. `tasks` Collection
Represents operational dispatch of health workers to field locations.

```javascript
{
  _id: ObjectId,
  clusterId: { type: ObjectId, ref: 'clusters', required: true },
  assignedOfficerId: { type: ObjectId, ref: 'users', required: true },
  assignedWorkerId: { type: ObjectId, ref: 'users', required: true },
  priority: { type: String, enum: ["LOW", "MEDIUM", "HIGH", "URGENT"] },
  instructions: String,       // Specific guidance for the worker
  dueDate: ISODate,
  status: {
    type: String,
    enum: ["PENDING", "IN_PROGRESS", "VERIFIED", "CANCELLED"],
    default: "PENDING"
  },
  verificationReport: {
    verifiedAt: ISODate,
    confirmedCases: Number,
    onGroundObservations: String,
    suspectedEnvironmentalSource: String,
    immediateSuppliesProvided: [String] // e.g. ["ORS", "Zinc tablets", "Chlorine tablets"]
  },
  createdAt: ISODate,
  updatedAt: ISODate
}
```

---

## 5. `actions` Collection
Audit log of administrative and clinical intervention decisions.

```javascript
{
  _id: ObjectId,
  clusterId: { type: ObjectId, ref: 'clusters' },
  taskId: { type: ObjectId, ref: 'tasks' },
  performedBy: { type: ObjectId, ref: 'users', required: true },
  actionType: {
    type: String,
    enum: [
      "STATUS_CHANGE",
      "DISPATCH_HEALTH_WORKER",
      "COMMUNITY_ADVISORY_ISSUED",
      "WATER_TESTING_REQUESTED",
      "MEDICAL_CAMP_SCHEDULED",
      "SUPPLIES_DISPATCHED"
    ]
  },
  details: String,
  metadata: Object,
  timestamp: { type: ISODate, default: Date.now }
}
```

---

## 6. `facilities` Collection
Directory of Primary Health Centers (PHCs), sub-centers, dispensaries, and civil hospitals.

```javascript
{
  _id: ObjectId,
  name: String,               // e.g. "Primary Health Centre - Ward 4"
  type: { type: String, enum: ["PHC", "CHC", "SUB_CENTRE", "DISTRICT_HOSPITAL", "DISPENSARY"] },
  ward: String,
  location: {
    type: { type: String, enum: ['Point'], default: 'Point' },
    coordinates: [Number],    // [longitude, latitude]
    address: String
  },
  contactNumber: String,
  medicalOfficerInCharge: String,
  availableResources: {
    bedCapacity: Number,
    testingKitsAvailable: Boolean,
    orsStockAvailable: Boolean
  },
  createdAt: ISODate,
  updatedAt: ISODate
}
```
