## ⚠️ Important Safety and Medical Disclaimer

> **SwasthyaGrid is NOT a medical diagnosis system.**  
> SwasthyaGrid is an intelligent operational decision-support and early-signal monitoring platform designed for public health departments and field health workers. The platform **does NOT diagnose diseases or confirm health conditions with certainty**. All alerts, clusters, and priority scores generated by the system represent aggregated statistical and geographic signals designed to trigger timely on-ground investigation. **All alerts require human and health-worker field verification.**

---

## 1. Project Overview
**SwasthyaGrid** bridges the critical gap between grassroots community health occurrences and rapid public health response. By capturing decentralized health reports from citizens and frontline health workers, SwasthyaGrid aggregates symptom signals, detects emerging geographic and temporal clusters, computes an explainable priority score, and arms health department officers with actionable spatial insights to deploy frontline health workers before localized issues escalate into full-scale outbreaks.

---

## 2. The Problem
- **Delayed Surveillance**: Traditional public health systems rely heavily on formal clinical registries or hospital admissions, often delaying outbreak detection by 1 to 2 weeks.
- **Signal Blindspots**: Localized clusters of symptoms (e.g., waterborne illnesses, vector-borne spikes, seasonal contagions) are noticed by citizens and community workers first, but lack a unified, real-time ingestion pipeline.
- **Black-box Overwhelm**: When alerts do reach health administrators, they often lack contextual explainability, making it difficult to allocate scarce healthcare personnel and medical resources effectively.

---

## 3. The Solution
SwasthyaGrid provides a unified, intelligent pipeline:
1. **Low-friction Reporting**: Quick, multi-lingual reporting portal for citizens and field health workers.
2. **Signal Clustering & Density Analysis**: Geo-spatial and temporal clustering to catch localized surges early.
3. **Explainable Risk Scoring**: A transparent score (0–100) explaining *why* an alert is prioritized (velocity, vulnerability, proximity to shared water sources).
4. **Interactive GIS Map & Command Dashboard**: Real-time visualization for health department officers.
5. **Closed-Loop Verification Dispatch**: Rapid digital assignment of verification tasks to nearby health workers (e.g., ASHA/ANM workers) to confirm conditions on the ground.

---

## 4. Key Features
- **Citizen & Frontline Worker Ingestion**: Intuitive web form with geolocation, symptom picker, and environmental observations.
- **Dynamic Spatial Clustering**: Automatic grouping of reports by spatial proximity and temporal acceleration.
- **Explainable Priority Score**: Multi-factor scoring engine with readable breakdown of contributing risk factors.
- **Interactive Health Map**: High-performance GIS visualization built with Leaflet and heat/cluster pins.
- **Task Dispatch & Field Verification**: End-to-end task workflow for community health workers with mobile-ready checklists.
- **AI Signal Extraction & Insights**: Extraction of structured signals from unstructured notes and interactive decision queries.
- **Privacy by Design**: Anonymized citizen reports, strictly preserving sensitive personal identifying information.

## 5. Technology Stack

### Frontend
- **React (v18+)** with **Vite** — Fast, modern component-based UI
- **Tailwind CSS** — Utility-first, responsive, and accessible styling
- **React Router (v6+)** — Client-side declarative routing
- **Leaflet & React Leaflet** — Interactive GIS mapping and spatial overlays
- **Recharts** — Responsive charting for symptom velocity and trend analytics
- **Axios** — Robust API client
- **Lucide React** — Consistent iconography

### Backend
- **Node.js & Express.js** — Scalable RESTful API server
- **MongoDB & Mongoose** — NoSQL database with 2dsphere spatial indexing
- **JSON Web Tokens (JWT) & bcryptjs** — Secure role-based authentication
- **CORS & dotenv** — Cross-origin resource sharing and configuration management

### AI / Intelligence Layer
- **Google Gemini API / NLP Services** — Unstructured signal extraction, report summarization, and interactive query assistant
- **Deterministic Risk Engine** — Transparent, rule-based mathematical scoring

## 8. Local Setup & Installation

### Prerequisites
- **Node.js** (v18 or higher recommended; v24 supported)
- **npm** (v9 or higher)
- **Git**
- **MongoDB** (Local instance or MongoDB Atlas URI for Phase 2 onwards)

### 1. Clone the Repository
```bash
git clone https://github.com/pranavverma0311-create/SwasthyaGrid.git
cd SwasthyaGrid
```

### 2. Environment Variables Configuration
Copy the template `.env.example` into `.env` for backend and frontend configuration:
```bash
cp .env.example .env
```
> **Security Note:** Never commit a `.env` file containing actual secrets, passwords, or API keys to Git.

### 3. Install Dependencies
Install dependencies for both backend and frontend from the root:
```bash
# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install

# Return to root
cd ..
```

---

## 9. Running the Application

### Running the Backend
From the root directory or `backend/`:
```bash
cd backend
npm run dev
```
The API server starts by default on `http://localhost:5000`.  
Verify health check at: `http://localhost:5000/api/health`

### Running the Frontend
From the root directory or `frontend/`:
```bash
cd frontend
npm run dev
```
The Vite development server starts by default on `http://localhost:5173`.

## 12. Privacy and Ethics Note
SwasthyaGrid is engineered according to privacy-by-design standards:
- Citizen reporting does not mandate personal identifiers; anonymous reporting is supported.
- Exact home coordinates are aggregated to approximate ward/sector grid cells before analytical exposure.
- All algorithmic recommendations are explainable and advisory, keeping certified human health officials firmly in control of all health responses.
